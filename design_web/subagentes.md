Campos que abarca el Diseño Web
Todo lo que ves y usas en una web es responsabilidad de alguien. Aquí están todos los campos, qué hacen y qué profesional lo ejecuta.

1. DISEÑO VISUAL (UI Design)
Qué es: La apariencia. Todo lo que se ve.
Cubre:

Colores, tipografías, espaciados
Iconos, ilustraciones, imágenes
Botones, tarjetas, formularios
Consistencia visual en toda la web
El sistema de diseño (las reglas visuales)

Herramientas: Figma, Adobe XD
Profesional: UI Designer / Diseñador de interfaces

2. EXPERIENCIA DE USUARIO (UX Design)
Qué es: Cómo se siente usarla. La lógica detrás de la interfaz.
Cubre:

Flujo de navegación (cómo el usuario llega de A a B)
Arquitectura de la información (dónde va cada cosa)
Wireframes (esqueletos de las páginas antes del diseño)
Pruebas con usuarios reales
Reducción de fricciones en el proceso de compra o registro

Herramientas: Figma, Miro, Maze
Profesional: UX Designer / UX Researcher

3. ANIMACIONES E INTERACCIONES (Motion / Interaction Design)
Qué es: Todo lo que se mueve o reacciona.
Cubre:

Animaciones de entrada y salida de elementos
Microinteracciones (el botón que vibra al hacer clic)
Transiciones entre páginas
Efectos de scroll (parallax, scrollytelling)
Loaders y estados de carga
Animaciones 3D o WebGL

Herramientas: After Effects, Lottie, GSAP, Framer, Three.js
Profesional: Motion Designer / Interaction Designer / Desarrollador frontend creativo

4. DESARROLLO FRONTEND
Qué es: Convertir el diseño en código real que funciona en el navegador.
Cubre:

Estructura HTML de la página
Estilos CSS (lo que el diseñador definió, llevado a código)
Responsividad (que se vea bien en móvil, tablet y escritorio)
Animaciones en código
Velocidad de carga y rendimiento visual
Accesibilidad (que la usen personas con discapacidad)

Herramientas: HTML, CSS, JavaScript, React, Tailwind, Next.js
Profesional: Frontend Developer

5. DESARROLLO BACKEND
Qué es: Todo lo que ocurre detrás de la pantalla.
Cubre:

Base de datos (dónde se guardan usuarios, productos, pedidos)
Lógica del servidor (qué pasa cuando alguien compra o se registra)
APIs (conexión entre la web y otros servicios)
Seguridad y autenticación
Emails automáticos, notificaciones

Herramientas: Node.js, Python, PHP, MySQL, PostgreSQL
Profesional: Backend Developer

6. CONTENIDO VISUAL (Fotografía / Video / Ilustración)
Qué es: Las imágenes reales que habitan el diseño.
Cubre:

Fotografía de producto o corporativa
Video hero (el video de fondo en portada)
Ilustraciones personalizadas
Iconografía propia de la marca
Infografías

Profesional: Fotógrafo · Videógrafo · Ilustrador · Diseñador gráfico
Nota importante: Un diseño perfecto con fotos de stock genéricas pierde el 70% de su impacto. El contenido visual propio es tan importante como el diseño.

7. COPYWRITING / CONTENIDO
Qué es: Las palabras que convencen.
Cubre:

Textos de la web (headlines, descripciones, CTAs)
Tono de voz de la marca
SEO on-page (palabras clave en el contenido)
Blogs y artículos
Textos de landing pages y anuncios

Profesional: Copywriter · Content Strategist · Redactor SEO
Nota: El copy es lo que convierte. Un diseño bonito con copy débil no vende.

8. SEO TÉCNICO
Qué es: Que Google encuentre y posicione la web.
Cubre:

Estructura de URLs
Velocidad de carga (Core Web Vitals)
Metaetiquetas y datos estructurados
Sitemap y robots.txt
SEO local (para negocios físicos)
Linkbuilding

Herramientas: Search Console, Ahrefs, Semrush
Profesional: SEO Specialist / SEO Técnico

9. BRANDING / IDENTIDAD VISUAL
Qué es: La personalidad visual de la marca antes de que exista la web.
Cubre:

Logo y variantes
Paleta de colores oficial
Tipografías de marca
Tono de comunicación
Manual de marca (las reglas de todo lo anterior)

Profesional: Brand Designer / Diseñador de identidad corporativa
Nota: Sin branding definido, el diseñador web inventa una identidad. A veces funciona, a veces no. Lo ideal es tener el branding antes de diseñar la web.

10. RENDIMIENTO Y INFRAESTRUCTURA
Qué es: Que la web cargue rápido y no se caiga.
Cubre:

Hosting y servidores
CDN (distribución global del contenido)
Optimización de imágenes y código
Seguridad (SSL, backups, protección)
Dominio y DNS

Profesional: DevOps / Sysadmin / Backend con conocimiento de infraestructura

¿CUÁNTOS NECESITAS?
Web básica (landing, portafolio):
UI Designer + Frontend Developer. Con suerte son la misma persona.
Web de empresa mediana:
UI/UX Designer + Frontend + Backend + Copywriter + SEO básico.
E-commerce real:
Todo lo anterior + fotógrafo de producto + especialista en conversión (CRO).
Startup con producto digital:
Todo lo anterior + Motion Designer + DevOps + UX Researcher.
